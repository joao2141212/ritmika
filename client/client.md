# client.md

Frontend React/Vite do Ritmika. Leia src/src.md antes de alterar interface, autenticação, serviços ou dados.

## Arquivos

- .env.local: variáveis públicas de runtime do frontend; nunca imprimir valores.
- .gitignore: exclusões locais do cliente.
- README.md: instruções próprias do frontend.
- eslint.config.js: regras de lint.
- index.html: documento HTML de entrada.
- vite.config.js: build e servidor Vite.
- package.json e package-lock.json: dependências e comandos do cliente.
- public/public.md: ativos públicos e redirects.
- src/src.md: código React, serviços, dados e estilos.

dist é build gerado e node_modules é dependência instalada; ambos ficam fora da documentação operacional de arquivos.
