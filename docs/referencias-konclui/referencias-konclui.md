# Referências visuais do Koncluí

Mapa canônico das capturas autorizadas usadas para comparar fluxos e contratos
de produto do Koncluí com o Ritmika.

## Regra de uso

- As imagens são referências de comportamento e organização, não autorização
  para copiar marca, textos ou identidade visual.
- O Koncluí permanece somente leitura.
- Dados do cliente visíveis nas capturas não devem ser usados como fixtures de
  QA nem transformados em regras hardcoded do Ritmika.
- Uma captura de preview móvel dentro do Portal do Gestor não prova o
  comportamento do aplicativo operacional instalado.
