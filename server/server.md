# server.md

API auxiliar Node usada pelo projeto fora do boundary principal do frontend.

## Arquivos

- server.js: ponto de entrada HTTP do servidor.
- db.js: conexão e helpers de banco local/auxiliar.
- package.json e package-lock.json: dependências do servidor.
- routes/routes.md: rotas HTTP.

node_modules é dependência instalada e não faz parte do inventário.
